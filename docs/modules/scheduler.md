# Module Map — `src/core/scheduler`
_Ported from the reference app on 2026-08-07 (migration step 13) and corrected for this repo.
Originally generated by a review agent on 2026-06-23 at commit 33ec20a. Regenerate when this slice

> **Roles here are cosmetic.** This app has no role model: the auth adapter answers `true` to all
> three role getters (`src/core/user/authAdapter.ts`), so every `requiredRole: 'admin'` below and
> every in-view `isAdmin` check passes for any signed-in user. The metadata is kept so the module
> stays byte-comparable with the reference and gains real gating for free if roles ever land.

## Purpose

Admin-only background-jobs dashboard for the in-house scheduler. Operators browse registered jobs,
inspect a job's run history and individual run detail (payload snapshot + replay lineage), trigger/
pause/resume jobs, replay past runs, and view a "needs attention" health summary (failed / overdue /
orphaned jobs + recent-outcome rollup). Every route is gated to the `admin` role.
